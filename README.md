> **Developed as part of the DiGiLIANS (Digital Pioneers Initiative) Data Analytics Track**

An interactive **Power BI** dashboard built on a B2B Sales Pipeline dataset to monitor revenue, sales opportunities, product performance, and sales team efficiency through clean data modeling and dynamic visualizations.

![B2B Sales Dashboard Preview](images/dashboard.png)

---

## 🎯 Key Dashboard Insights
* **Revenue & Deal Metrics:** Total Revenue, Average Deal Value, and Deal Size Distribution.
* **Sales Trends & Pipeline:** Monthly Sales Trend and Sales Opportunity Status tracking.
* **Product Analytics:** Top Performing Products and Product Win & Loss Analysis.
* **Team & Sector Performance:** Top Sales Agents, Revenue by Sales Manager, and Revenue by Business Sector.

---

## 🔍 Key Features & Implementation
* **Data Cleaning:** Prepared and transformed raw pipeline data using **Power Query**.
* **Data Modeling:** Designed an optimized **Star Schema** data model.
* **DAX Calculations:** Built custom **DAX Measures & Calculated Columns** for KPIs and win/loss metrics.
* **User Experience:** Added interactive KPI cards, dynamic slicers & filters, **Navigation Buttons**, and **Report Page Tooltips** for deeper drill-down analysis.

---

## 🛠️ Tech Stack
* **BI & Visualization:** Microsoft Power BI
* **ETL & Modeling:** Power Query, Star Schema
* **Calculations:** DAX (Data Analysis Expressions)

---

## 🚀 How to View
1. Download the `.pbix` file from this repository.
2. Open it using **Microsoft Power BI Desktop**.
3. Use the navigation buttons, slicers, and hover tooltips to explore sales performance across agents, managers, products, and sectors.
